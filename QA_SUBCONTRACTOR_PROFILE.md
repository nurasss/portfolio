## Where I can help a QA agency

For a small, agreed scope, I can support an existing QA lead with:

1. **Release smoke & regression:** execute a prioritized checklist for sign-in, user roles, forms, core customer journeys, and important error paths.
2. **API validation:** check representative REST success/error responses, authorization boundaries, idempotency and failure behavior in a test environment.
3. **Bug reporting:** record environment, reproducible steps, expected/actual behavior, severity and supporting evidence when available.
4. **Retesting & handoff:** verify fixes and provide a concise release-risk summary; the agency/client retains release approval.
5. **AI-feature checks:** evaluate defined sample prompts, fallbacks and human-handoff paths; this is application QA, not a security certification.
